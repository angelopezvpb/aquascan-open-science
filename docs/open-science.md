# Open Science Philosophy

## Why Open Science?

AquaScan investigates groundwater — a critical resource for billions of people.
We believe that:

1. **Scientific methods for water prospecting should be transparent**
2. **Results should be reproducible by independent researchers**
3. **Data quality and provenance should be verifiable**
4. **Baselines should be accessible so that progress can be measured**

## What Open Science Means for AquaScan

### Public
- Dataset specification and schema
- Ingestion code for public data sources
- QA/QC methods (deterministic)
- Baseline models and evaluation
- Experiment protocols and configuration
- All scientific claims and methodology

### Private (Proprietary Layer)
- Production GeoAI models and trained weights
- Client-specific Ground Truth data
- AutoCal advanced algorithms
- Regional proprietary models
- Commercial infrastructure and operations

## Open Science Practices

- **Reproducibility**: Every experiment must be rerunnable by anyone
- **Data versioning**: Dataset versions are tracked alongside code
- **Provenance**: Every data product traces back to its RAW origin
- **Negative results welcome**: Dry wells are as important as productive ones
- **Pre-registration**: Experiment protocols are defined before running

## Limitations

AquaScan Open Science is a research framework. It is NOT:
- A commercial water detection service
- A guarantee of finding water
- A substitute for professional hydrogeological studies

The public repository deliberately excludes production AI components
to protect commercial interests while maximizing scientific openness.
