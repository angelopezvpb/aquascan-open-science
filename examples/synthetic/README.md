# Synthetic engineering fixtures

Everything in this directory (and the `SYNTHETIC_ENGINEERING_FIXTURE` labeled
data inside `src/aquascan/physical/synthetic/`) is **synthetic** and exists to
exercise parsers, pipelines, encoders and contracts.

It is NOT Ground Truth for real AquaScan groundwater performance.

Run the physical-stack smoke demo:

```bash
python -m aquascan.physical.synthetic.fixtures
```
